# Gemini RAG Chatbot 🧠📄

A Retrieval-Augmented Generation (RAG) chatbot built using Google's Gemini API, LangChain, ChromaDB, and Streamlit.

Upload your PDF documents, ask questions, and get context-aware answers instantly — powered by real-time embeddings and AI reasoning.

## 🔧 Features

- Upload multiple PDFs
- Chunk text and embed using Gemini
- Store/retrieve context using ChromaDB
- Natural question answering with Gemini LLM
- Streamlit UI for easy interaction

## 🚀 How to Deploy (Streamlit Cloud)

1. Clone this repo
2. Add `GEMINI_API_KEY` in Streamlit Cloud → Settings → Secrets
3. Deploy the app with `rag_streamlit.py` as the main file
